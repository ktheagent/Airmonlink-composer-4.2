# Shortcuts and Input

- `Ctrl+K`: command palette
- `Ctrl+Shift+C`: Composition Hub
- `Ctrl+N`: new score
- `Ctrl+O`: open
- `Ctrl+S`: save
- `Ctrl+Shift+S`: save as
- `Ctrl+Z`: undo
- `Ctrl+Y`: redo

The command palette exposes connected interface commands. Shortcut maps are normalized and checked for duplicate or reserved combinations.

Input may come from mouse, computer keyboard, on-screen piano or MIDI. All paths create the same semantic notes and exactly four user-facing voice layers.
